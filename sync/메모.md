# Claude Code → 테니스어플 세션 인수인계 (2026-09-01)

로컬(Claude Code)에서 진행된 변경 사항. **이 저장소의 index.html이 최신본** — app/index.html을 이걸로 교체하고 이어서 개발할 것.

## 완료된 것
1. 정복 지도를 실제 제주 행정경계 14구역으로 교체 (통계청 GeoJSON → SVG path, REGIONS는 d(path) 필드, renderMap polygon→path)
2. 구역 탭 TOP5 랭킹보드 (regionRanking / 무주공산 화면)
3. **단·복식 ELO 분리(A안 확정)** — 서버에 004_split_elo.sql 적용·스모크 테스트 완료 (profiles에 singles/doubles_pts·matches·wins, confirm_match v2 통합+종목 동시 반영, rankings_singles/doubles 뷰). 앱 랭킹에 [전체|단식|복식] 탭 + 데모 selector sPts/dPts
4. 서버 경기 카드 복식 지원 (sv-kind + 파트너·상대2 슬롯, report_match에 4인 팀 전달)
5. 로그인 모달 "둘러보기"(skipAuth, sessionStorage) + 경기 기록 기본값 복식
6. **랠리 촬영 모드**(lvCam) — 링버퍼, 점수 탭 = 직전 랠리 클립(점수 라벨), 45초 무득점 시 구간 파기
7. **점수 리모컨**(lvRC) — Realtime 채널 score:코드4자리, 파트너 폰/갤럭시워치 브라우저에서 원격 점수 입력(로그인 불필요), 촬영 모드와 결합 시 원격 탭→클립
8. 배포: GitHub Pages https://yjc20170201-sudo.github.io/tennismate/ (재배포는 로컬 배포하기.bat — Storage/Edge Function 호스팅은 supabase.co가 HTML을 text/plain으로 강제해 폐기)
